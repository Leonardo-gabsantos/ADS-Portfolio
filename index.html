Solução: Implementamos linguagem natural conectada a uma base de dados de saúde por meio de web scrapping para conectar o usuário a informações úteis de saúde, como vacinas disponíveis por idade, por localização, retorno de UBS proximas, esclarecimento de dúvidas de saúde direto por linguagem natural, e retorna as UBS mais próximas do usuário em tempo real.
